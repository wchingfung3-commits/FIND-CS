# FIND CS

香港全行業客服導航平台 — 幫用戶找到「實際可以聯絡真人客服的方法」。

## 概述

FIND CS 不是單純提供公司電話或網址，而是提供從客服入口到真正真人客服之間的完整操作路徑。

## 功能

- 公司搜尋（模糊搜尋 + 自動完成）
- 6 個行業分類入口
- Simple / Router 兩種客服模式
- 確切真人客服操作步驟
- 驗證狀態及服務時間
- 全站免責聲明

## 技術

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React icons
- Hash-based routing

## 開發

```bash
npm install
npm run dev
```

## Build

